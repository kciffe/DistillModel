# 苏联第一代弹道导弹核潜艇：H级

N级攻击型核潜艇的研制成功，加速了苏联弹道导弹核潜艇和飞航导弹核潜艇的研制工作。早在1956年苏联党和政府就发出了关于研制658型导弹核潜艇的命令，这也是当时的冷战形势所迫。1958年底，N级交付海军。1959年，美国率先建成了第一代弹道导弹核潜艇“乔治·华盛顿”号。

658型由“红宝石”设计局设计，C·H·科瓦列夫为总设计师，现任“红宝石”设计局领导的И·Д·斯巴斯基院士，是当时的副总设计师。

# 658型的主要战术技术要素

H级是第一代弹道导弹核潜艇，658型是H级中的第一型，称H-1型。

658型的作战任务是用弹道导弹攻击敌陆上基地、港口和岸上军事目标。和629型（G级）相比，658型有更大的续航力，可以远离基地，深入到接近敌领土的海区，在敌反潜区外发射弹道导弹。限于当时苏联弹道导弹的技术水平，658型装备的仍是和629（G-1型）相同的、水上发射的P-13型弹道导弹。

658型水上排水量4030吨, 水下排水量5300吨, 最大长度114.0米, 最大宽度9.2米, 平均吃水7.5米; 2座压水反应堆, BM-A型 (2×70兆瓦), 1台60-ⅡM型齿轮传动式汽轮主机组39200 马力（亦有 60-Ⅱ型的报道，35000 马力，和 N 级相同）。双轴、双桨。备用动力有柴油发电机，2 台Ⅱ Γ -400 型直流发电机组（柴油机为 M-820 型）2 × 400 千瓦。另有交流电源 400 赫，380 伏。28CM-1 型蓄电池，2 × 112 块。Ⅱ Γ -116 型经航电机，推进功率 2 × 450 马力。水上航速 21 节，水下航速 26 节。水下续航力（节）31000 海里（26 节）（全功率）。极限下潜深度 300 米，工作下潜深度 250 米。自给力 50 昼夜，艇员 128 人。

武器: H级有几种改进型。658型为H-1型, 装备3枚水上发射的P-13弹道导弹。首部有4具533毫米和2具400毫米的鱼雷发射管。艇尾还有2具400毫米的鱼雷发射管。可发射C 3 T -65、53-65K和53-61型鱼雷。12枚533毫米的鱼雷存放在架上, 4枚在管中。另有4枚400毫米的鱼雷, 总共有鱼雷20枚(有资料说共22枚, 其中400毫米的鱼雷有6枚)。

# 658 型的结构和总布置

658型是紧接着在627型（N级）之后研制成功的弹道导弹核潜艇。为了赶进度，658型没有经过方案设计阶段，就在1957年一季度完成了技术设计，而直接从627型“拿来”了多项技术和装备，吸取了629型（G级）的研制成果。可以说，658型就是在627型的基础上，在艇中部嵌入一个导弹舱而构成的。

658型为双壳体结构。和627型不同的是，658型的艇首没有用627型“鱼雷”形的艇首，而采用水面舰艇形的艇首。这主要是为了照顾艇水面状态航行时的性能，不致产生埋首现象，能破浪前进，有利于发射导弹和进行导弹发射前的准备工作。

全艇分为10个舱。第4舱就是导弹舱。其余的9个舱和627型的分舱布置基本相同。

第1舱——鱼雷舱；第2舱——居住舱和蓄电池舱；第3舱——中央指挥舱；第5舱——柴油发电机和辅机舱（相当于627型的第4舱）；第6舱——反应堆舱（627型为第5舱）；第7舱——主机舱（627型为第6舱）；第8舱——经航电机舱（627型为第7舱）；第9舱——辅机、厨房和住舱（627舱的第8舱）；第10舱——尾鱼雷舱和住舱。

658型的隔舱壁都是平面舱壁。这是和627型不同的。627型有4个球面舱壁，有3个逃生舱：第1舱、第3舱和第8舱。这3个舱都是有出入舱口的。

在 658 型的轻外壳上试装了用橡胶制成的消声瓦，但试验结果并不理想。使用后因粘贴不牢而脱落一些。

# 658型（H-1型）的武器和观导设备

658型装备P-13型弹道导弹。这型导弹也曾装备于629型(G-1型)上。不过首先交艇的几艘629型艇，因为P-13型的研制进度赶不上装艇要求，就先暂时装备了P-11ΦM型导弹。658型也一样，最初也是装备P-11ΦM型导弹。1961年10月P-13型导弹研制成功后，才将艇改装为装备P-13型导弹的。

P-13型导弹由385设计局，在B·Ⅱ·马克耶夫领导下完成研制。

P-13型是液体燃料型导弹，长度11.8米，直径1.3米，射程560千米，起飞重量13.6吨，单弹头，但可装核弹头。这是一型只能从潜艇水上状态发射的弹道导弹，圆概率偏差为4千米。

“圆概率偏差”是指所发射的所有弹头的50%，预计都能命中瞄准点为圆心所作出的圆的半径值。圆概率偏差用以描述导弹的命中精度。P-13型导弹的“圆概率偏差”为4千米，显然命中精度是不高的，但消灭大面积的目标，如城市、海港、海军基地等还是足够的。

P-13型导弹采用液体燃料火箭发动机。液体燃料由燃料和氧化剂组成，燃料的燃烧不需要外界空气。但是P-13型导弹的燃料是一种TΓ-02燃料（二甲苯胺和三乙胺的混合剂），这种燃料的蒸汽在化合时自燃，是一种高危火源。因此艇上只将装有氧化剂（AK-27И，四氧化二氮在浓硝酸的溶液）的导弹放入发射筒中，而将燃料另置于耐压艇体外的专用容器中，而3枚导弹所用的燃料要分开放。在进行发射准备工作时才将燃料注入导弹。

导弹发射前，需预先做好各项准备工作。潜艇上浮后从发射筒中升起导弹，进行发射。从潜艇上浮至发射第3枚导弹的时间为12分钟，然后潜艇再下潜。这12分钟，658型艇就完全暴露在水面状态。

可以说，P-13型导弹的维护保养和操作使用都是非常不便的。

艇上配备有“冥王星-658型”综合导航系统。声呐设备则有MΓ型“北极”主被动声呐站，MΓ-10噪声定向站，“亮光-M”型水声通信站和MΓ-13型探测敌声呐的侦察声呐站。雷达站有“信天翁”（或译“海鸥”）攻击雷达，“涌浪”侦察雷达和“铬-K”敌我识别器。鱼雷射击指挥仪是“列宁格勒-658”型。此外，还有一些导航设备和潜望镜。

658型还可以从鱼雷发射管发射MΓ-14水声对抗设备。1967年又采用了MΓ-24型自航式声干扰器，从艇上的模拟弹和信号弹发射装置（ВИПС）发射（ВИПС装置在R级上也有，用以发射ИП模拟弹和ИСП信号弹）。MΓ-24使用深度30~40米，能连续工作30分钟。这是用以干扰敌水声设备工作的。

# 658M 型 (H-2 型)

658型的研制取得了成功,苏联有了弹道导弹核潜艇,然而在水面状态发射导弹并停留12分钟,暴露了潜艇,不符合隐蔽性的要求。水面状态的潜艇会成为敌反潜飞机的最佳目标。

1958年苏联就已开始研制新一型导弹P-21型。P-21型可以从潜艇的水下状态发射，并且有比P-13型导弹更大的射程，提高了攻击的隐蔽性。

1965～1970年间就在658型艇的大修期间，所有8艘艇都换装了P-21型，这就是658M型（H-2型）。

P-21型弹道导弹长14.2米，直径1.3米，起飞重量19.7吨，液体燃料发动机，射程1420千米，单弹头，圆概率偏差1.3千米，P-21型导弹的总设计师也是B·Ⅱ·马克耶夫。

为进行P-21型导弹的试验，改装了一艘G级潜艇，成为629 B型。629 B型艇于1960年12月完成了导弹的发射试验后，列入了现役。1964年苏联就开始了629A型的改装，是为G-2型、同时也对658型（H-1型）进行装备P-21型导弹的改装，成为658M型（H-2型）。

弹道导弹的水下发射有“湿式”和“干式”两种方式，658M型是用“湿式”从水下发射P-21型导弹的。发射前，先往发射筒内注水，使发射筒内和舷外的海水压力相等，便于开启发射筒的盖子。发射时，导弹发动机就在筒内点火。发动机喷出的燃气可将导弹抛出筒外，导弹进入大气。因为发射时导弹处于有水的发射筒内，所以称“湿式”发射。又因导弹发动机在筒内就点火，也称“热发射”，这是苏联潜艇采用最多的一种发射方式。

# 701型（H-3型）——658型的改装型

P-21 型导弹射程虽然有 1420 千米，但是每艘 658M 型艇仍是只能装 3 枚。

1969～1970年又对658型的第6艘K-145艇进行了改装，成为701型(H-3型)。每艇装备6枚P-29型导弹。P-29型导弹也是由B·Π·马克耶夫任总设计师。

P-29型导弹长13.0米，直径1.8米，起飞重量33.3吨，射程7800千米（也有不同的报道）。单弹头，液体燃料，水下“湿式”发射，这已经是洲际弹道导弹了。

由于导弹尺寸较大，6枚导弹仍只能排单排，使得艇加长了13米，为127米。艇的总设计师为H·Φ·舒利任何。装6枚导弹的指挥室围壳，可能是世界上所有核潜艇中最长的。

701型仅建1艘，用作试验P-29型导弹，但试验并不完全成功。以后P-29型导弹成功地装备在D级核潜艇上。

# 建造和服役

658型在北德文斯克建造, 共建8艘。括弧中未注明的为开工日期:

K-19 (1958.10.17 开工, 1960.11.12 服役); K-33 (1961.7.6); K-55 (1962.8.12); K-40 (1962.12.28): K-161 (1963.6.15); K-145 (1963.12.29); K-149 (1964.2,12); K-178 (1964.6.30)。均在北方舰队服役。

其中K-145后来改装为701型(H-3型)。1963年和1968年K-55和K-178先后调往太平洋舰队，是从冰层下航渡到太平洋舰队的，以堪察加为基地。后在上世纪70年代这两艇改装为658T型鱼雷艇。K-40艇从1977年起成为通信艇KC-40艇。

658型首艇K-19艇在服役期间曾历经多次险情。1961年7月4日在挪威海域进行训练并准备发射导弹（训练），在浮出水面后，因为主循环泵和辅泵被卡住，反应堆活性区急剧升温。当时艇上有3枚带核弹头的导弹，一旦发生爆炸，离海区100千米的美海军基地也要受到影响。在紧急情况下，艇员用了2个小时就安装好了临时的反应堆冷却系统，排除了爆炸危险。因为抢救工作是在反应堆舱和与其相邻的舱室中进行的，抢修的艇员由于受到大剂量的辐射，有14人先后死亡。进行抢修的艇员都是明知道会受到大剂量辐射，而不顾个人安危，抱定不惜牺牲的精神，挽救了潜艇和艇员，避免了一次核爆炸事故。

1962～1964年修理期间，将K-19艇的反应堆舱切割，并换上了两座新的反应堆。失事的反应堆（尚有未耗尽的核燃料）就沉入了新地岛的阿勃列西莫夫港。这种处理方法，在今天是绝对不会允许的，因为污染了海洋环境。

1969年11月15日，K-19艇在巴伦支海与一艘秘密跟踪的美SSN-615艇（“长尾鲨”号）相撞，两艘艇都受到损伤。

1972年，K-19艇上又起火，死了28人。以后又到北德文斯克的“星星”修理厂进行修理。修好后，又在一次航行回港时，艇上发生火灾，不过没有人员伤亡。

西方曾将K-19艇称为“寡妇制造者”，并于2001年以该艇事故为题材拍摄了《K-19：寡妇制造者》电影。更有消息传出，1966～1969年在艇上服役的厨师弗拉基米尔·罗曼诺夫现在已是俄罗斯的亿万大享。他准备将这艘即将销毁的K-19艇买下，改造成博物馆，停泊在莫斯科河。

苏联潜艇艇员有时表现出一些带迷信的观点，可能渔民和海员在大自然面前多少有些迷信的。K-19艇下水时抛掷的香槟酒瓶就没有破，因为艇外壳有橡胶制成的消声瓦。K-19艇出事后，有很多人就回忆起这件事，说这是不祥之兆。作者也有这样的经历，知道苏联艇员是不让妇女上艇的（在建造中，还未交付海军的艇可以），说这会带来晦气。后来，这个习俗也传到了我国潜艇部队。
